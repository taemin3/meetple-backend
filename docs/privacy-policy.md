# 밋플 개인정보 처리방침 운영 메모

## 공개 위치

- 웹: `https://api.meetple.shop/privacy-policy`
- 앱: 가입 화면 및 `프로필 > 약관 및 정책 > 개인정보 처리방침`
- 계정 삭제: `https://api.meetple.shop/account-deletion`
- 정책 버전: `2026-09-12`

## 코드와 대조한 범위

- 회원: 이메일, 비밀번호 암호화 값, 이메일 인증 시각, 닉네임, 프로필 이미지, 한줄 소개, 지역
- 활동: 모임, 참여 신청, 북마크, 채팅, 알림, 읽음 상태와 알림 설정, 약관 기록
- 기기·위치: 앱 설치 식별자, 플랫폼, FCM 토큰, 위치 권한 허용 시 현재 좌표와 장소 검색어
- 임시 인증정보: 인증번호 5분, 가입·비밀번호 재설정·탈퇴 토큰 15분, 갱신 토큰 기본 14일
- 이벤트: Outbox 기본 7일, Kafka 일반·재시도·DLQ 최대 14일, 복구 안전 조건 미충족 시 정리 지연 가능
- 인프라: AWS 서울 리전 기반 저장·처리, CloudWatch 로그 14일, RDS 자동 백업 설정 범위 1~35일, 최종 스냅샷 최대 1년
- 외부 서비스: AWS, NAVER Cloud 지도·검색, Google Firebase Cloud Messaging

## 배포 전 운영자 확인 항목

아래 항목은 저장소만으로 법적 운영 주체를 확정할 수 없으므로 Play Console 제출 전에 실제 계약·계정 정보와 대조한다.

1. `밋플 운영팀`을 Play Console에 표시되는 개발자 또는 사업자 실명으로 바꿔야 하는지 확인
2. `support@meetple.shop` 수신과 개인정보 권리 요청 처리 담당자 확인
3. Google FCM의 실제 처리 국가, 국외 이전 근거와 보유 기간을 Firebase 계약·설정과 대조
4. 운영 Terraform 변수의 RDS 자동 백업 보존 기간이 공개한 최대 35일 범위인지 확인
5. 데이터베이스 교체·폐기 시 생성되는 최종 스냅샷을 1년 안에 수동 삭제하는 운영 절차와 담당자 지정
6. Google Play 데이터 보안 설문에서 위치, 개인정보, 메시지, 사진, 앱 활동, 기기 식별자 항목을 같은 기준으로 신고

이 문서는 구현 대조용 메모이며 법률 자문을 대신하지 않는다. 공개 본문은 `src/main/resources/static/privacy-policy/index.html`, 앱 제공 본문은 `V17__publish_privacy_policy.sql`과 로컬 초기화 코드에 있다.
