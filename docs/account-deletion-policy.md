# 밋플 계정 삭제 정책 및 API

## 정책 요약

- 계정 행은 모임·참여·채팅 순서·약관 동의 기록의 외래키 무결성을 위해 유지한다.
- 이메일은 무작위 폐기 주소로 치환하고 원 이메일 조회 대상에서 제외한다. 따라서 탈퇴 직후 같은 이메일로 재가입할 수 있다.
- 비밀번호는 무작위 값의 단방향 해시로 교체하고 이메일 인증 시각, 닉네임, 소개, 지역, 프로필 이미지 키를 제거한다.
- 모든 Refresh Token과 Push Device Token을 제거한다. Access Token 검증은 Refresh Token 세션 존재 여부도 확인하므로 기존 Access Token도 즉시 거부된다.
- 회원 단위 채팅 세션 무효화 이벤트를 발행해 현재 WebSocket 세션을 닫고, 이후 STOMP CONNECT도 비활성 로그인 세션으로 거부한다.
- 프로필 이미지 오브젝트는 기존 `IMAGE_DELETE_REQUESTED` Outbox 흐름으로 삭제를 예약한다.

## 데이터별 처리

| 데이터 | 처리 | 이유/주의사항 |
| --- | --- | --- |
| Member 개인정보 | 이메일·비밀번호 익명화, 닉네임 고정, 소개·지역·프로필·인증 시각 제거, `deleted_at` 기록 | 복구와 로그인 차단, 원 이메일 재가입 허용 |
| 주최 모임 | 진행 중(`RECRUITING`, `FULL`) 모임 취소, 완료/취소 기록 유지 | 참여자에게 이미 형성된 서비스 기록과 상태 무결성 유지, 주최자는 익명 회원으로 표시 |
| 참여 신청 | 대기/승인 신청은 취소, 승인 인원 감소, 신청 메시지 제거 | 다른 모임의 정원 복구 및 자유 입력 개인정보 제거 |
| 북마크 | 전부 삭제 | 개인 선호 데이터로 보존 필요 없음 |
| 채팅 메시지 | 행과 순서는 유지하고 본문을 `[탈퇴한 회원의 메시지]`로 치환 | 방의 순서·중복 방지 키는 유지하면서 자유 입력 개인정보 제거 |
| 채팅 읽음 상태/알림 설정 | 전부 삭제 | 개인별 설정 데이터로 보존 필요 없음 |
| 알림 | 전부 삭제 | 개인 수신함 데이터로 보존 필요 없음 |
| Push Device Token | 전부 삭제 | 기기 식별·발송 정보 제거 |
| 약관 동의 기록 | 익명 Member ID, 문서 버전, 동의 행위, 기록 시각만 유지 | 동의 사실에 대한 최소 증적. 실제 법적 근거와 보존기간은 운영 정책/법무 검토로 확정 필요 |

모임 상태, 채팅 순서, 약관 동의 기록처럼 보존하는 값은 계정의 원 이메일·닉네임·프로필과 연결되지 않는다. 운영자는 법령 또는 분쟁 대응을 이유로 보존하는 각 항목의 목적·기간·파기 절차를 개인정보처리방침에 구체적으로 고지하고, 확정 근거가 없는 데이터는 보존하지 않아야 한다.

## API 계약

### 앱 내 탈퇴

`DELETE /api/v1/users/me`

```json
{
  "currentPassword": "현재 비밀번호"
}
```

- Bearer 인증 필수
- 성공: `200`
- 잘못된 비밀번호: `400`, code `10009`
- 미인증/만료/탈퇴 후 기존 토큰: `401`
- 이미 탈퇴한 회원을 서비스 계층에서 다시 처리: `409`, code `10904`

### 웹 이메일 인증 탈퇴

1. `POST /api/v1/account-deletions/email-verifications`
2. `POST /api/v1/account-deletions/email-verifications/confirm`
3. `POST /api/v1/account-deletions`

발송 API는 이메일 존재 여부와 관계없이 같은 성공 응답을 사용한다. 인증번호는 5분, 확인 시도는 5회, 재전송 대기는 1분이며 IP 단위 및 전체 요청 제한을 기존 이메일 인증 설정에서 재사용한다. 확인 성공 시 기본 15분 유효한 계정 삭제 전용 토큰을 발급한다. 최종 API가 토큰을 원자적으로 소비하므로 같은 토큰을 다시 사용할 수 없다.

최종 요청:

```json
{
  "email": "user@example.com",
  "accountDeletionToken": "일회용 토큰",
  "confirmed": true
}
```

## 외부 페이지와 배포 후 확인

- 로컬/배포 경로: `/account-deletion` 및 `/account-deletion/`
- 운영 배포 후 예상 URL: `https://api.meetple.shop/account-deletion`
- 배포 후 인증 없이 `200`, 모바일 레이아웃, 발송→확인→최종 삭제, 재사용 토큰 거부를 별도로 확인한다.
- Play Console에서 앱을 선택한 뒤 `앱 콘텐츠(App content) → 데이터 보안(Data safety) → 계정 삭제` 질문에 위 HTTPS URL을 입력한다. 콘솔 언어·개편에 따라 메뉴 명칭은 달라질 수 있다.
- 실제 고객지원 주소와 앱/개발자 표기, 개인정보처리방침의 보존 항목·기간을 운영 정보와 대조한 뒤 제출한다.

이 저장소 변경만으로 실제 배포 또는 Google Play 심사가 완료되는 것은 아니다.
