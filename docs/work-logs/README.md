# Work Logs

이 폴더는 Codex가 백엔드 브랜치 단위로 수행한 작업 흐름을 추적하기 위한 기록 공간이다.

## 목적

- 사용자가 어떤 요청을 했는지 남긴다.
- Codex가 어떤 도구와 명령을 사용했는지 남긴다.
- 어떤 순서로 코드와 문서가 수정됐는지 남긴다.
- 검증 명령과 결과를 남겨 오류 원인 추적에 활용한다.
- PR 본문보다 자세한 작업 맥락을 보관한다.

## 작성 시점

Codex가 브랜치를 만들어 백엔드 파일을 수정하고 커밋/푸시하는 단위 작업에서는 가능하면 작업 로그를 함께 작성한다.

단순 설명, 짧은 질의응답, 파일을 바꾸지 않는 확인 작업은 생략할 수 있다.

## 파일 이름

파일 이름은 날짜와 브랜치명을 기준으로 작성한다.

```text
YYYY-MM-DD-branch-name.md
```

예시:

```text
2026-05-26-feat-meeting-participation.md
2026-05-26-fix-auth-token-rotation.md
```

## 작성 규칙

- `TEMPLATE.md`를 복사해서 작성한다.
- 사용자 요청, 작업 흐름, 실행 명령, 사용 도구, 변경 파일, 검증 결과를 기록한다.
- 토큰, 비밀번호, 개인 정보, 운영 비밀 값은 기록하지 않는다.
- `.env` 값이나 로컬 DB/Redis 비밀번호는 기록하지 않는다.
- 명령 출력 전체가 길면 핵심 결과만 요약한다.
- 실패한 명령도 원인 추적에 필요하면 기록한다.
- PR 본문에는 요약만 적고, 자세한 흐름은 작업 로그에 남긴다.
